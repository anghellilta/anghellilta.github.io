## 🛡️ Asset Protection & Security

All original visual assets and creative artworks are protected by built-in security features:
- **Right-Click Prevention**: Context menus are disabled across artwork images to prevent unauthorized downloads.
- **Drag-and-Drop Shield**: Image dragging is disabled to prevent quick extraction.
- **Keyboard Shortcut Interception**: Common browser download/save shortcuts (`Ctrl+S`, `Cmd+S`) are intercepted on media containers.
- **CSS Touch Callout Suppression**: Mobile long-press "Save Image" popups are suppressed (`-webkit-touch-callout: none`).

## 🚀 Local Development Setup

To run and preview the portfolio locally on your machine:

### Option 1: Using VS Code Live Server (Easiest)
1. Open the project folder in [VS Code](https://code.visualstudio.com/).
2. Install the **Live Server** extension.
3. Right-click `index.html` and click **"Open with Live Server"**.

### Option 2: Using Node.js / NPX
```bash
# Using npx serve
npx serve .

# Or using the included server.js
node server.js
```
Then navigate to `http://localhost:3000` or `http://localhost:5000` in your web browser.

## 🌐 Deployment Guide

### Deploying to GitHub Pages (`anghellita.github.io`)
1. Ensure this repository is named `anghellita.github.io` under the `anghellilta` GitHub account.
2. Push the latest files to the `main` branch:
   ```bash
   git add .
   git commit -m "Update portfolio assets, documentation, and pages"
   git push origin main
   ```
3. In GitHub, go to **Settings > Pages**.
4. Set **Source** to `Deploy from a branch` and select `main` / `/(root)`.
5. Your website will be live at: **[https://anghellilta.github.io/](https://anghellilta.github.io/)**
